# NETFLIX-EDA

# 🎬 Netflix Data Analysis Project

An interactive **EDA project on Netflix content** to understand trends in movies, TV shows, countries, ratings, and genres.

---

## 🔍 Analysis Covered

* Movies vs TV Shows
* Country-wise Content Distribution
* Ratings & Genre Popularity
* Release Year Trends
* Duration Analysis

---

## 📊 Dataset Size

* 8,800+ Titles
* 12 Features including Genre, Country, Release Year

---

## 📈 Key Insights

* Movies dominate Netflix content
* USA and India lead in content production
* Most titles added after 2015

---

## 🛠 Tools Used

Python | Pandas | Matplotlib | Seaborn
